## Priority rule

Until a specialist completes a theorem-level comparison against the literature, use:

`PROVED_EXACT / PRIORITY_NOT_ESTABLISHED`

Do not use phrases such as “first proof,” “new theorem,” or “novel formula” solely because repository searches did not find an identical string.
