# OPAC-016 Prior-Art / Novelty Boundary

Relevant established background includes:

1. Thomas Zaslavsky, signed-graph theory: balance, switching, linear representations, and links to classical root systems.
2. Paola Cellini and Mario Marietti, root polytopes and projection geometry for finite crystallographic root systems.
3. Classical Type-A and Type-C root-polytope geometry.

This release uses those areas as background and does not claim that signed-graph switching, Type-C cross-polytopes, or root-polytope projection methods are original.

Before claiming publication novelty, an expert should determine whether the exact formula
`kappa(C_n,U)=1` with no balanced block and `2-2/b_max` otherwise
already appears explicitly in prior literature or follows immediately from an existing named theorem.

Current project status is therefore:
`PROVED_EXACT`, not `PRIORITY_ESTABLISHED`.
